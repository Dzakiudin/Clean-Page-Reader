# Clean Page Reader 🧹

[](https://opensource.org/licenses/MIT)

Ubah halaman web yang berantakan menjadi artikel yang bersih dan nyaman dibaca dengan satu klik. Ekstensi ini secara otomatis menghapus iklan, *sidebar*, *popup*, komentar, dan elemen mengganggu lainnya, menyajikan konten utama dalam mode baca yang fokus dan minimalis.

![alt text](https://github.com/Dzakiudin/Clean-Page-Reader/blob/main/public/before-after-comparison.jpg?raw=true)

## ✨ Fitur Utama

  - **Mode Baca Sekali Klik**: Langsung aktifkan mode baca yang bersih dengan menekan tombol ekstensi.
  - **Deteksi Konten Cerdas**: Secara otomatis menemukan dan mengisolasi artikel atau konten utama pada halaman.
  - **Bebas Gangguan**: Menghilangkan iklan, navigasi, *sidebar*, *footer*, dan komentar yang tidak relevan.
  - **Desain Minimalis**: Tampilan yang dioptimalkan untuk kenyamanan membaca dengan tipografi yang jelas.
  - **Ringan dan Cepat**: Tidak membebani browser dan bekerja dengan cepat di berbagai situs berita dan blog.
  - **Kembali dengan Mudah**: Tombol "Kembali" yang jelas untuk memuat ulang halaman ke versi aslinya.

## 🚀 Instalasi Manual

Karena ekstensi ini belum dipublikasikan di Chrome Web Store, Anda perlu menginstalnya secara manual:

1.  **Unduh Repositori**: Unduh atau `git clone` repositori ini ke komputer Anda.
2.  **Buka Ekstensi Chrome**: Buka browser Chrome, ketik `chrome://extensions` di bilah alamat, lalu tekan Enter.
3.  **Aktifkan Mode Pengembang**: Di pojok kanan atas halaman, aktifkan saklar **"Developer mode"** (Mode Pengembang).
4.  **Muat Ekstensi**: Klik tombol **"Load unpacked"** (Muat yang belum dibongkar).
5.  **Pilih Folder Proyek**: Arahkan dan pilih folder tempat Anda menyimpan file ekstensi ini.
6.  **Selesai\!** Ikon sapu 🧹 "Clean Page Reader" akan muncul di bilah alat browser Anda.

## 💡 Cara Menggunakan

1.  Buka halaman artikel atau berita yang ingin Anda baca.
2.  Klik ikon **Clean Page Reader** 🧹 di toolbar Chrome Anda.
3.  Halaman akan langsung disegarkan ke dalam mode baca yang bersih.
4.  Untuk kembali ke halaman asli, klik tombol **"✕ Kembali ke Halaman Asli"** yang muncul di pojok kanan atas.

## ❤️ Motivasi

Seringkali kita merasa frustrasi saat membaca artikel di internet karena terlalu banyak iklan, video putar otomatis, dan *popup* yang mengganggu. "Clean Page Reader" lahir dari kebutuhan untuk menciptakan pengalaman membaca yang tenang dan fokus, seperti membaca buku. Ekstensi ini adalah solusi sederhana untuk mendapatkan inti dari sebuah tulisan tanpa kebisingan visual.
